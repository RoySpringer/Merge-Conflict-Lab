GEEN HINTS

Drie versies, één productregel

Nog te doen
De regel

Een gebruiker krijgt alleen toegang als het account actief en betaald is én de gebruiker niet geblokkeerd is.

Beide branches begonnen bij dezelfde basis. Bepaal welke oplossing de bedoeling volledig bewaart.

Basis
const access = user.active;
HEAD
const access = user.active
  && !user.blocked;
feature/payment
const access = user.active
  && user.hasPaid;

NIEUWE PRODUCTREGEL

Los het inlogconflict op

Nog te doen
Het besluit

Na een beveiligingsreview vervangt het team inloggen met een gebruikersnaam volledig door inloggen met een e-mailadres. Gebruikersnamen mogen niet meer als inlognaam werken.

HEAD bevat de oude manier. De inkomende branch voert het nieuwe besluit uit. Welke oplossing past bij de productregel?

HEAD
const identity = user.username;
return signIn(identity, password);
feature/email-login
const identity = user.email;
return signIn(identity, password);

De situatie

Een merge raakt vier bestanden. Selecteer alle paden waarvoor Git nog een inhoudelijke beslissing van jou nodig heeft. Een gewone lokale wijziging hoort niet bij je selectie.

Unmerged paths:

GROENE TESTS

Toch goedkeuren?

Nog te doen
De situatie

Een teamgenoot heeft een conflict opgelost. De bestaande tests voor bedrag en valuta zijn groen. In HEAD stond ook een analytics-aanroep; die ontbreekt in het eindresultaat.

HEAD vóór de merge
analytics.track("price-calculated");
return rounded;
Opgelost resultaat
return {
  amount: rounded,
  currency: "EUR"
};
